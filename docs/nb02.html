Predicción del Incumplimiento de Pago en Tarjetas de Crédito usando Machine Learning

02. Verificación del protocolo experimental

El protocolo usa semilla aleatoria 42 (para que los resultados se puedan reproducir) y validación cruzada anidada con 5 pliegues externos y 5 internos, y la variable objetivo es default_payment_next_month. Se probó la separación de variables y objetivo con un conjunto sintético de 5,000 filas (22.46 % de clase positiva) y se confirmó que el objetivo es binario. Finalmente, se verificó que el conjunto de datos real procesado (29,965 filas y 21 columnas) contiene el objetivo y las columnas categóricas definidas en el protocolo.
